考试与答题

从试卷列表到交卷

📋

试卷中心

  • 状态角标实时计算：未开始 / 答题已开放 / 已结束，灰绿红三色区分
  • 卡片显示试卷名、科目、类型（自由 / 强制）、起止时间与计时方式
  • 每 15 秒自动刷新列表，进入答题 / 详情 / AI 页自动暂停，返回即恢复
  • 标为「强制」且已到开放时间的试卷，进入首页即自动跳转答题
  • 下拉刷新；区分「加载失败，请下拉刷新重试」与「暂无试卷」两种空态
✍️

答题页

  • 支持 单选 / 多选 / 填空 / 简答 四种题型
  • 两种计时：总计时（整卷倒计时）与每题计时（逐题倒计时，可按题配置）
  • 到时自动交卷；每题计时模式下自动进入下一题，最后一题自动交卷
  • 答题卡按题型分组，题号格三色标识：当前题蓝、已答绿、未答灰
  • 总计时可自由跳题；每题计时只能顺序推进，回看已答题进入只读并提示「此题已作答，仅可查看」
  • 离开页面立即停止计时；多选题提交前自动排序归档
🏆

成绩与解析

  • 总得分与满分对照展示
  • 按单选 / 多选 / 填空 / 简答四类分别统计得分
  • 逐题呈现我的答案、标准答案与解析
  • 对照着色：标准答案绿色，选错橙色，一眼看出差异
  • 每题可一键「问 AI」，自动带上题干、题型、选项、标准答案与我的答案
∑

  • 题干、选项、解析全部支持 LaTeX 公式原生渲染
  • 兼容 $…$ 行内、$$…$$ 块级、\(…\) 与 \[…\] 多种写法
  • 自动还原 HTML 实体与 Unicode 转义、修复断裂的 LaTeX 反斜杠、补齐未闭合花括号
  • 题目可附带配图，自动适配卡片宽度
  • 公式渲染失败时回退显示原始 LaTeX 文本，便于排查
